MONITOR FACTURARE - versiune desktop Windows

Pornire:
1. Dublu-click pe MonitorFacturare.exe
2. Se va deschide automat interfața în Microsoft Edge sau Google Chrome.
3. Nu este necesară instalarea Python, Node.js sau a altor componente.

IMPORTANT:
- Nu este un executabil one-file cu auto-extragere.
- MonitorFacturare.exe pornește doar un server HTTP local pe 127.0.0.1 și deschide aplicația în browser.
- Salvarea PDF/XLSX este legată de un dialog nativ Windows prin endpoint-ul local /__native_save.
- Nu descarcă programe sau componente de pe internet.
- Datele aplicației sunt păstrate local în browserul folosit.

Fișiere:
MonitorFacturare.exe  - launcher desktop Windows 64-bit
app.html              - interfața aplicației
README.txt            - instrucțiuni
SHA256.txt            - hash SHA-256 al executabilului
